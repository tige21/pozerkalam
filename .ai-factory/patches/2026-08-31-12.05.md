# Неровные отступы надписей: дребезг базовой линии карточки и три левых края на старте

**Date:** 2026-08-31 12:05
**Files:** index.html
**Severity:** low

## Problem

Надписи выглядели неаккуратно: в карточке #coach иконка, бейдж передачи, мини-руль и чип
прыгали по вертикали и стояли с разными промежутками; на стартовом экране было три разных
левых края (заголовок, буллеты, списки), буллеты без маркеров с рваными переносами;
список уровней имитировал колонку маркера тремя `&nbsp;`.

## Root Cause

Инлайн-элементы карточки добавлялись по одному с ад-хок значениями (`vertical-align:-1px`,
`-3px`, `1px`; margin 2/3/4/6/8 px) — каждый выравнивался «на глаз» относительно текста,
а не по общей оси. Стартовые буллеты центрировались собственным блоком
(`margin:12px auto; max-width:560px`) и потому не совпадали с левым краем заголовка,
живущим на паддинге карточки. Маркер «▶» в списке уровней был частью текста строки,
и его ширина не равнялась трём `&nbsp;` у остальных строк.

## Solution

- Карточка: все инлайн-элементы (`.ci/.cgear/.cw/.cg/.cq`) на `vertical-align:middle`
  с одинаковыми отступами (4px справа у ведущих, 5px слева у хвостовых); `.cwhy` на всю
  ширину. **Flex не подходит**: пробовал `display:flex;flex-wrap:wrap` — длинный текст
  k-gear переносится по max-content и уносит иконку на отдельную строку; инлайн-поток
  оставляет естественные переносы.
- Старт: буллеты классом `.startlist` — левый край общий с заголовком, висячий отступ
  (`padding-left` + `::before`-маркер в гаттере), переносы строк ровные.
- Список уровней: маркер текущего «▶» через `li.cur::before` в отдельной колонке
  (`padding-left:20px`), а не текстом.

Логирование: не добавлялось — чисто CSS/markup, поведения нет. Проверка — скриншоты
до/после всех состояний (старт, k-gear, act+чип+почему, compact).

## Prevention

- Инлайн-декор в текстовой строке выравнивать одним правилом (`vertical-align:middle`
  + единый шаг отступов), а не подгонкой каждого элемента.
- Блок внутри оверлея не центрировать собственным `margin:auto` — левый край задаёт
  паддинг карточки, всё содержимое живёт от него.
- Колонку маркеров делать `padding-left` + `::before`, никогда — пробелами в тексте.
- Flex-wrap не годится для «иконка + длинное предложение»: перенос по max-content.
