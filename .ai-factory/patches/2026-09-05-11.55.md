# Экзамен: поворот без поворотника не начислял балл — фильтр курса зоны срабатывал внутри зоны

**Date:** 2026-09-05 11:55
**Files:** index.html (`violationsTick`, цикл по `turnZones`)
**Severity:** high

## Problem

На экзамене (уровень 27) можно проехать оба перекрёстка и развернуться без поворотника — счёт остаётся 0.
На городских уровнях 23–26 тот же детектор давал тост «Манёвр без поворотника», поэтому баг был виден
только на экзамене. Воспроизведено синтетическим проездом (setBody по дуге + `violationsTick`): после выхода
из зоны `_inZone` оставался `true`, штраф не срабатывал.

## Root Cause

Зоны поворота экзамена несут `dir` — курс входа, чтобы две зоны на одном кресте ловили правый и левый проход
по отдельности. Фильтр `Math.abs(angNorm(car.th - tz.dir)) > 50° → continue` стоял в начале тела цикла и
проверялся **каждый кадр**. Внутри зоны курс уходит от `dir` на 90°, `continue` выбрасывал зону раньше
проверки выхода `(!inside && tz._inZone)`, и ветка со штрафом не достигалась никогда. Городские зоны без
`dir` фильтром не затрагивались — отсюда «работает в городе, не работает на экзамене».

## Solution

Фильтр по `dir` применяется только пока зона не «взята»: `if(!tz._inZone && tz.dir!==undefined && …) continue;`.
Дальше зона отслеживается до выхода независимо от курса. На выходе добавлена трассировка
`console.warn('[FIX:no-blinker] выход из зоны: поворот N°, поворотник был/не был')`.
Проверка: `tools/exam-check.js` → `examCheck()` в консоли страницы — пять сценариев (правый без/с поворотником,
прямо, разворот без/с) дают 1/0/0/1/0 баллов; headless-регрессия 18 демо / 0 warn.

## Prevention

- Фильтр «актуальна ли зона» и отслеживание «внутри → выход» — разные фазы: любое условие, зависящее от
  текущего состояния машины (курс, скорость), нельзя ставить перед проверкой выхода, иначе выход теряется.
  Правило: gate на входе, состояние — до выхода.
- Детекторы нарушений проверять синтетическим проездом (`setBody` по траектории + `violationsTick`), а не
  только вручную: сценарий «без поворотника должно быть +N» занимает секунду и ловит именно этот класс.
- Тест-страница в браузере кэшируется: после правки `index.html` открывать с cache-buster (`?nocache=<ts>`)
  и проверять `fn.toString().includes(<маркер правки>)` — иначе прогон подтверждает старый код.
