# Кнопки входа VK ID и Яндекс ID выглядели как второстепенные серые кнопки

**Date:** 2026-10-03 01:45
**Files:** index.html, tools/account-check.mjs, specs/features/acct/vhod.feature
**Severity:** medium

## Problem

Владелец после выкатки входа: «нужны нормальные кнопки для авторизации — в spark уже сделаны».
В игре «Войти через VK ID» и «Войти через Яндекс ID» были `.ghost` — прозрачные кнопки с серой
рамкой, такие же, как «Выбрать уровень» и «Как это устроено». Вход через знакомый сервис не
узнавался. Попутно нашлось: между нажатием и уходом на страницу провайдера идёт запрос к сервису,
и второе нажатие в это время начинало второй вход — игрок не видел, что первое сработало.

## Root Cause

Флоу входа переносился из spark по документации и серверному коду, а внешний вид кнопок — нет.
Кнопки собраны по правилу оверлея игры «одна громкая, остальные тихие»: «Поехали» громкая, вход —
вторичное действие, значит `.ghost`. Правило про иерархию верное, но у кнопок входа через чужой
сервис есть свой обязательный вид — цвет и логотип провайдера, по ним пользователь узнаёт, куда его
ведут. В spark это уже было решено (`src/modules/auth/presentation/components/oauth-buttons`), но
компоненты UI при переносе не открывали. Состояние «запрос ушёл» не нарисовали, потому что в моке
гейта сервис отвечал мгновенно.

## Solution

`acctBtnsHTML` рисует фирменные кнопки как в spark: VK ID — сплошная `#0077ff` с белым логотипом VK,
Яндекс ID — чёрная с красным кругом и белой «Я», высота 48, скругление 24, цветная тень, белый
полужирный текст; на тёмной карточке у чёрной кнопки тонкая светлая обводка. Логотипы — SVG прямо в
разметке (пути взяты из spark): CSP пускает их без скриптов, а виджеты `@vkid/sdk` тянут чужой
скрипт. `authStart` блокирует обе кнопки до ответа сервиса и показывает индикатор на нажатой.
Отдельный `:hover` для фирменных кнопок — общий `button:hover` красил бы Яндекс в синий; анимация
индикатора гаснет при `prefers-reduced-motion`. Порядок VK ID → Яндекс ID не менялся.

## Prevention

- Переносишь фичу из соседнего проекта — открой и его компоненты UI, не только сервер и доки.
- Кнопки входа через сторонний сервис рисуются в фирменных цветах провайдера, правило «вторичная —
  ghost» к ним не относится.
- Любая кнопка, после которой идёт сетевой запрос, блокируется до ответа; мок в гейте отвечает с
  задержкой, иначе двойное нажатие не видно (`@acct-start-once`).
- Цвет и высота проверяются гейтом по вычисленным стилям (`@acct-buttons-brand`), а не глазами.
