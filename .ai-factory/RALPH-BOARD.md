Промт цикла (повторяется каждую итерацию): «Прочитай .ai-factory/RALPH-BOARD.md и выполни ровно одну итерацию по его правилам».
Обещание завершения — слово `BOARD_DONE` в promise-теге. Выводить ТОЛЬКО когда каждая открытая задача доски

## Правила итерации

0. Прочитать журнал (внизу) и доску: `bash ~/.claude/hooks/vikunja-board.sh ~/.config/pozerkalam-vikunja.env`.
   API-рецепты — CLAUDE.md «Task Board — Vikunja» и память `vikunja-tracker`. Апдейты задач — ПОЛНЫМ payload.
1. Пока в журнале нет строки `verify: flow-plan OK` — прогнать `/aif-verify` для
   `.ai-factory/plans/kanban-vikunja-codegraph-flow.md`; дефекты починить, закоммитить `/aif-commit`, записать результат.
2. Взять верхнюю ОТКРЫТУЮ задачу доски без открытых блокеров, у которой в журнале нет `done`/`ждёт владельца`.
   Перенести в Doing (`POST /projects/3/views/12/buckets/8/tasks {"task_id":N}`). В журнал: `#id — в работе (итерация N)`.
3. Полный AIF-цикл по ней: `/aif-plan fast <суть>` → `/aif-implement` → `/aif-verify` → `/aif-commit`.
   Fast-план живёт в `.ai-factory/PLAN.md`; после коммита файл удалить (иначе SessionStart-хук считает план открытым).
   Всё, что агент физически может сделать, делается до конца: код, билды, скриншоты, тексты, документы, проверки.
   Тесты по CLAUDE.md: правки `index.html` → headless-регрессия (0 warn по всем DEMOS); правки подсказок → `learner.js`.
4. Закрытие задачи:
   - выполнена целиком → на доске `done:true` полным payload + бакет 9; в журнал `#id — done: <что сделано, хеш коммита>`;
   - остаток за владельцем (аккаунты площадок, кнопка «отправить», ИП, платежи, юридические проверки, решения о ценах) →
     сделать всю агентскую часть, добавить комментарий к задаче
     (`PUT /tasks/{id}/comments {"comment":"<p><b>Готово:</b> …</p><p><b>Осталось владельцу:</b> …</p>"}`),
     вернуть в To-Do (бакет 7); в журнал `#id — ждёт владельца: <готово / осталось>`;
   - Backlog с внешним условием (M3 CDN — по метрикам; товарный знак — ручная проверка) → не делать,
     комментарий на доске + журнал `ждёт владельца` с одной строкой обоснования.
5. Новая работа, найденная по ходу (баг, долг, идея) — в том же ходе задача на доске (priority, label, blocked-связи)
   + упоминание в журнале. Такие задачи тоже входят в условие завершения.
6. Одна задача за итерацию (шаг 1 — сверх неё). Если по одной задаче 3 итерации без прогресса — записать
   `#id — заблокировано: <причина>`, комментарий на доске, считать её `ждёт владельца`.
   В конце итерации — короткий отчёт: что закрыто, что ждёт владельца, что следующее. Тег обещания не писать.

- Править только `index.html`; `codegraph-src/index.js` — генерат (pre-commit пересобирает сам).

  залипший lock — `pkill -f ms-playwright-mcp`. Headless-регрессия: `computeIdealPath` через `loadLevel` по всем `DEMOS`
  с перехватом `console.warn`; суррогатный demoStep-цикл даёт ложные хиты — не использовать.
