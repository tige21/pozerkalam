## Цель

Ученик, прошедший приложение, отработал **все манёвренные элементы практического экзамена ГИБДД (категория B)** и получил экзаменационную обкатку:

1. Недостающие упражнения: эстакада (остановка/трогание на подъёме с контролем отката), задний ход по коридору, экзаменационная остановка у тротуара.

## Задачи

### Фаза A — органы управления и физика под экзамен

**A1. Поворотники.**
`index.html`: секции input / HUD / touch. Состояние `car.blink` (`'L'|'R'|null`) — **событийное, переключается в `pressKey`, а не поллится из `input`**: `demoStep:3914` обнуляет весь `input` каждый кадр, поллинг сломал бы демо. Клавиши `KeyQ`/`KeyE` (физические коды — безопасны на ЙЦУКЕН), тач-кнопки у `#tgear`, HUD-индикатор (мигающие стрелки у спидометра + повторители в кабине через `emitLit`), звук реле через `tone()`. Автосброс — **по изменению курса**: выключать, когда `|angNorm(th − th_на_момент_включения)| ≥ 60°` и руль вернулся к нулю; отмена по проходу руля через ноль не годится — «разворот в три приёма» проходит ноль многократно и давал бы ложные отмены. Поле `blinker:'L'|'R'` в фазах — коуч пишет «включи правый поворотник», карточка показывает стрелку. В DEMOS — поле `seg.blink`, `demoStep` включает поворотник на входе в сегмент: городские демо обязаны сами показывать ритуал, иначе детекторы C9 оштрафуют собственную демонстрацию. Просадка привычки — главный источник баллов на экзамене, поэтому фаза A первая.
Лог: нет. Зависимости: нет.

**A2. Уклон и откат-метрия.**
`build()` получает фабрику `rampZone(rect, angle, grade)`; `stepCar` перед ветками режимов добавляет `car.vel += slopeA*dt`, где `slopeA = −9.81·grade·dot(fuv(car.th), gradDir)` внутри зоны. `P` держит намертво (уже даёт `slow(brake*2.2)` — проверить достаточность на 16 %). Откат-метр: при `dir≠0` накапливать смещение против знака `car.gear` в зоне уклона, отдавать в `curS` для фаз (`rollback` в метрах). Рендер: наклонная плоскость `pushQuad` с высотой по `grade` (машина визуально поднимается — `bodyPos` даёт u,v; высоту `y` подмешать в `emitCarMesh`/камеру только визуально, физика остаётся плоской 2D — зафиксировать это комментарием-инвариантом).
Лог: `console.warn` если машина покидает зону уклона со скоростью > maxR (диагностика клампа). Зависимости: нет.

**A3. Ручник.**
Клавиша `KeyX` + тач-кнопка + строка в HUD (значок (!) как на приборке). Держит машину на уклоне при любом селекторе (аддитивное `slow(CAR.brake*1.5)`), трогание с ручником глушит разгон вдвое (чувствуется ошибка). В фазах поле `handbrake:true` — для эстакадного сценария «зафиксируй → тронься».
Лог: нет. Зависимости: A2 (без уклона ручник бессмыслен).

### Фаза B — недостающие упражнения

**B4. Уровень 20 «Эстакада».**
`build()`: подъезд → рампа (`rampZone`, 10–12 %) → стоп-линия на подъёме → площадка → спуск. Фазы: подъезд → остановка у линии (допуск по `mline`) → фиксация (ручник или тормоз) → трогание с контролем `rollback ≤ 0.3 м` (штраф-фраза при 0.3–0.5, провал при >0.5 как на экзамене) → съезд. `marks()`: стоп-линия, зона отката подсвечивается красным при откате. DEMO: остановка, пауза `say`, трогание газом без отката (АКПП позволяет). Проверка: демо проходит; random-стоп не проходит.
Лог: warn в guard фазовой машины (непокрытое состояние). Зависимости: A2, A3.

**B5. Уровень 21 «Задний ход по коридору».**
Прямолинейное движение задним ходом 30 м в коридоре из конусов шириной 2.6 м с контролем по зеркалам (в кокпите фаза подсвечивает `mirror:'center'`). Экзаменационный смысл: элемент «движение задним ходом» + подготовка к боксу. Фазы с `act`/`goal` по `rear`-клиренсу, DEMO через `aim`.
Лог: нет. Зависимости: нет (параллельна B4).

**B6. Уровень 22 «Остановка у тротуара и высадка» (базовая версия, без статиста).**
Дриллы 16/18 учат чувствовать борт; этот уровень собирает экзаменационный ритуал: поворотник → плавное торможение → остановка ≤30 см от бордюра (порог из таблицы № 80) и не на зебре/остановке (декали запретных зон) → `P` → «высадка» (пауза) → поворотник → старт. Реюз `precGap`-механики для замера. Проезд статиста при старте **не здесь** — это расширение делает C10 после появления актёров.
Лог: нет. Зависимости: A1.

### Фаза C — город-lite

**C7. Фабрики городской инфраструктуры.**
Секция фабрик: `crossroad(type:'T'|'X', размеры)` — асфальтовые декали, осевые и краевые линии из `stripe`; `zebra(rect)`; `stopline(seg)`; `sign(kind, u,v)` — столбик `post` + billboard-грань с пиктограммой (Canvas-рисованные: STOP, «уступи», «главная», «движение по полосам», «пешеходный переход»), рендер через `pushFace`, шрифтовых/картиночных ассетов не добавлять. Знаки — обычные препятствия для коллизий (столб). **В `ED_KINDS:4055` новые фабрики не добавляем** — редактор вне скоупа плана; кастом-пады хранят только редакторные kind'ы, так что `edMake` неизвестный kind не встретит — зафиксировать инвариант комментарием у `ED_KINDS`.
Лог: нет. Зависимости: нет.

**C8. Машины-статисты.**
`pcar` получает вариант `actor` со скриптом движения: полилиния waypoint'ов + скорость, интеграция тем же велосипедным шагом (реюз `demoAim`/`sweep`), запуск по триггеру (положение игрока пересекло линию). Поза актёра обновляется **до** `resolveCollisions` в том же кадре; скорости ≤2 м/с — туннелирования на подшаге 1/120 нет. **Тень — живая, путём `carShadow`**: кэш `o._shadow` строится один раз в `loadLevel:2130`/`edRebuild:4162`, а `drawShadows:2657` пропускает только `knocked` — статичный кэш оставил бы тень актёра на месте старта. Столкновение со статистом = обычный хит + событие `yield-violation` для скоринга. Статисты двигаются в `frame` только на активном уровне; на `loadLevel` сбрасываются. Бюджет: ≤2 статиста на уровень, без per-frame аллокаций (правило adaptive-perf).
Лог: warn при статисте без валидного пути. Зависимости: C7.

**C9. Детекторы нарушений.**
Модуль `violations`: чистые функции над `curS`+геометрией уровня, события с типом и весом: пересечение стоп-линии без остановки; наезд на зебру при «пешеходе» (маркер-статист); выезд за осевую при повороте (полигон встречной полосы); поворот не из своего ряда; манёвр без поворотника (слушает `car.blink` в окне до фазы поворота); непропуск статиста («уступи»). Каждое событие — одноразовая защёлка на манёвр (паттерн `o._touch`). Вне экзамен-режима детекторы дают мягкую фразу коуча (`k-almost`), в экзамене — баллы. **Детекторы глушатся при активном `demo` и в headless-прогоне `computeIdealPath`** (расширить существующий список подавления say/hits/sound) — иначе расчёт идеальной траектории на `loadLevel` сам начисляет нарушения и сыплет warn'ы каждый заход.
Лог: warn при двойной защёлке (симптом сброса). Зависимости: C7, C8, A1.

**C10. Городские уровни 23–26.**
«Повороты на перекрёстке» (право: ближний радиус к своему краю; лево: выезд к центру, траектория по маркерам), «Разворот на перекрёстке», «Пешеходный переход и стоп-линия», «Уступи дорогу» (T-перекрёсток, знак, статист по главной). Каждый: фазы с `blinker`, marks, DEMO, лайфхаки, `transfer`. Фазовые цепочки — по правилам проекта (монотонный дискриминант, нормализация углов, полное покрытие состояний).
Лог: warn в guard-ветках. Зависимости: C7–C9.

### Фаза D — экзаменационный режим

**D11. Модуль exam: штрафная система.**
Таблица нарушений по приказу МВД № 80 в константе `PENALTIES` — {код, текст, баллы 5/3/1}; **при реализации сверить состав с действующей редакцией приказа** (реформа 01.04.2025 меняла регламент). Маппинг: события `violations` и хиты (`hitReason`) → баллы; порог: ≥5 — экзамен не сдан, немедленный стоп с причиной. Счёт в `exam.score`, события в `exam.log[]` (время, место, манёвр).
Лог: `console.warn` на каждое начисление (это и есть аудит-трейл). Зависимости: C9.

**D12. Экзаменационный маршрут и «молчаливый инспектор».**
Уровень-экзамен: большая карта (перекрёсток + улица с парковочными карманами + эстакада), последовательность 5 манёвров, **порядок и сторона рандомизируются** на старте (инспектор выбирает — как в жизни). Коуч заменяется командами инспектора («на перекрёстке налево», «выполните параллельную парковку», «остановитесь на эстакаде») — тот же `coachCard` с типом `k-exam`, но без подсказок «как», без маркеров и ideal-path. Принудительное отключение — **только в памяти, минуя `pressKey`**: строка 3613 пишет `trainer_marks` в localStorage при каждом toggle, экзамен не должен затирать настройки игрока; сохранить значения при входе, восстановить при выходе/рестарте. Туда же — **скрыть зазоры HUD и парктроник на время экзамена** (философия bestBlind: на реальном экзамене датчиков нет). `bounds` карты — из start + goal **всех этапов маршрута** + препятствий (правило инверсии bounds для пустых пад — маршрутные точки обязаны входить в расчёт). Демо для экзамена нет — есть у каждого входящего манёвра.
Лог: warn при недостижимой следующей точке маршрута. Зависимости: D11, D12b, B4, C10.

**D12b. Провал-состояние игры.**
У игры сейчас нет проигрыша — `win():4683` единственный конец (`game.done` + `winHTML`). Экзамен вводит первый fail-flow: набрал ≥5 баллов → немедленная остановка, экран «экзамен не сдан» с причиной (реюз `showOv`); «прервать экзамен» с `Escape`/кнопкой — с подтверждением. Учесть ловушку модальных состояний: `doAct('resume')` при `game.done` обязан вернуть протокол/фейл-экран (как сейчас возвращает win-экран), иначе из замороженной физики нет выхода. `restart()` сбрасывает `exam.score/log`.
Лог: нет. Зависимости: D11.

**D13. Протокол экзамена и разбор.**
Экран результата: сдан/не сдан, таблица ошибок из `exam.log` (манёвр → нарушение → баллы), под каждой — ссылка «отработать» на соответствующий уровень. ### Фаза E — МКПП

**E15. Физика МКПП.**
Режим `car.box:'AT'|'MT'` (настройка в меню, persist `trainer_gearbox`, дефолт AT). MT: педаль сцепления (клавиша `KeyC` удержание / тач-слайдер), передачи 1/2/R + N (задний ход и первая — хватает парковочных скоростей), модель: зона схватывания, обороты как функция скорости и передачи, **заглох** — бросок сцепления или трогание под нагрузкой на уклоне без газа; заглох = стоп двигателя, рестарт клавишей зажигания. Трогание в горку: газ+сцепление в точке схватывания+ручник — полный экзаменационный ритуал. Все пороги — производные от `CAR`.
Лог: warn на заглох с диагностикой (обороты, сцепление, уклон) — это обучающая телеметрия. Зависимости: A2, A3.

**E16. UI МКПП.**
Тахометр в HUD и на приборке кабины (`emitLit`), индикатор передачи, тач-слайдер сцепления (левый край экрана), вибрация схватывания звуком (`engineSound` модуляция оборотов уже есть — расширить). `shiftSel`-правила АКПП не трогаются; MT использует свой ввод. Первый-запуск-гайд (`tut`) получает MT-ветку.
Лог: нет. Зависимости: E15.

**E17. МКПП-контент.**
Эстакада-MT (главный сценарий: трогание с ручником, откат ≤30 см, счёт заглохов — 3 заглоха = провал попытки), экзаменационный маршрут в MT-режиме (D12 работает при обоих `box`). DEMO остаются на АКПП (правило: демо — доказательство решаемости геометрии, не трансмиссии); решаемость MT-эстакады доказывает скриптовый ученик с MT-вводом.
Лог: нет. Зависимости: E15, E16, B4, D12.
