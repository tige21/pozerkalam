## Контекст: факты
1. Сейчас весь звук — синтез (`audioBuild`, `audioUpdate`, `rpmStep`; шины `inn`/`out`/`ui` → `master` → компрессор). Владелец его отверг и просит записи, как с кузовами: готовый набор вместо самодельного.
2. `index.html` весит 2,30 МБ при бюджете 2,2 МБ (`embed.mjs --check` красный с 755cae5) — семплы в страницу не помещаются. И не должны: звук по умолчанию выключен, 9 игроков из 10 его не включают и не должны качать ни байта.
3. Гейты открывают игру через `file://`, а `fetch` из `file://` в Chrome не работает. Значит, без сервера звук остаётся синтезом, а `audio-check` поднимает свой статический сервер.
4. Кодек: MP3 декодируют все целевые браузеры, включая Safari и Chromium из Playwright (в нём нет AAC). Opus в Safari зависит от версии. У MP3 есть задержка кодера в начале файла — петля режется с запасом по краям (см. Р3).
5. Выкатка: `mv -f .next/* .` не перезаписывает непустой каталог; SW кладёт ресурсы в кэш по принципу cache-first в кэше сборки; билд ЯИ архивирует только `index.html`.

## Решения
- Р1. **Только CC0**, как у RgsDev и Kenney: Freesound с фильтром CC0, OpenGameArt, Kenney. Источник, автор, лицензия как написано на странице и что сделано с файлом — в `assets/src/audio/SOURCES.md`.
- Р2. **Выбирает владелец на прослушке**: по каждой категории 2–3 кандидата рядом и нынешний синтез для сравнения, все на одной громкости.
- Р3. **Формат**: MP3, моно, 44,1 кГц, 64–96 кбит/с. Петля записывается с запасом 0,15 с по краям из того же периодического материала, `loopStart`/`loopEnd` стоят внутри запаса, поэтому задержка кодера (≤ 0,06 с) не даёт щелчка ни в одном декодере. Имена с хэшем содержимого (`engine-idle.3f9a1c2e.mp3`): кэш браузера и SW не отдаст старый файл, а заливка не трогает файлы, которые сейчас играют.
- Р4. **Ленивая загрузка**: файлы качаются при первом включении звука (`initAudio`). Пока они грузятся и при любом отказе (`file://`, 404, ошибка декодирования) играет нынешний синтез, в консоли одно `[audio]`. Так же устроен отказ кузова → лофт.
- Р5. **Граф прежний**: семплы — источники в тех же шинах `inn`/`out`, всё идёт через `master`, поэтому пауза, фон и реклама глушат их без новых правил. Гейты `@app-audio-master` и `@app-audio-silent` остаются.
- Р6. **Мотор — две петли**, холостой ход и нагрузка: кроссфейд по оборотам и газу, `playbackRate` = обороты / обороты записи в пределах 0,7…1,6 (дальше запись звучит «бурундуком»). Модель автомата `rpmStep` не меняется.
- Синтезом остаются писки парктроника (это интерфейс) и всё, для чего на прослушке не нашлось записи.

### Ф2. Конвейер (ждёт выбора)
- [x] T4. `tools/audio/sfx.mjs` (ffmpeg): `assets/src/audio/*` → обрезка, петля с кроссфейдом и запасом по Р3, громкость, моно, MP3 → `audio/<имя>.<хэш8>.mp3` в корне репо, рядом с `index.html`. В `index.html` пишется блок-манифест между маркерами: имя → файл, начало и конец петли, обороты записи. Ключ `--check` краснеет, если исходник или параметры менялись без пересборки (`@app-audio-sfx-fresh`). Лог — одна строка на файл: имя, длительность, размер. Бюджет всех файлов — 400 КБ, проверка в `--check`.

### Ф3. Игра
- [x] T5. Загрузчик `sfxLoad()`: из `initAudio` один раз, `fetch` + `decodeAudioData` параллельно. Буферы кладутся в `SFX`; когда все готовы, `audioBuild` перестраивает источники, и звук переходит с синтеза на записи за 0,3 с. При отказе — одно `console.warn('[audio] записи не загрузились: …')`, синтез остаётся. Для `OfflineAudioContext` буферы передаются аргументом, чтобы WAV в гейте писался из тех же записей.
- [x] T6. Источники из записей:
  - мотор — две петли (Р6), шины — петля со скоростью и громкостью от скорости;
  - фон города — петля; поток — четыре голоса из записи проезда с панорамой `sndPan`; трамвай — петля хода, стыки, звонок;
  - разовые звуки — реле в такт лампе, селектор, ручник, удар, бордюр, гудок через формантную цепочку (если запись гудка выбрана, без неё);
  - синтез остаётся запасным путём всех источников.
- [x] T7. `audio-check` расширяется:
  - свой статический сервер для гейта (stdlib `http`);
  - `@app-audio-samples` — все файлы манифеста декодированы, каждый источник из `SFX` доходит до `master`;
  - `@app-audio-sample-fallback` — 404 даёт синтез и ровно одно `[audio]`;
  - `@app-audio-loop-seam` — на стыке `loopEnd → loopStart` нет скачка выше порога;
  - `@app-audio-render` — записи WAV собираются из семплов.

  Режимы `FAULT=nosample|nofallback|seam` красят соответствующую проверку. Новые сценарии — в `specs/features/app/zvuk.feature`, затем `gherkin-check` и `qa-checklist`.
