## Research Context
Память `perf-laptops-2026-10-12`, замер 12.10.2026 (Chrome, 1536×864 @1.25, CDP-замедление процессора,
режим без GPU — `--disable-gpu --disable-gpu-compositing`, трасса потоков):
- С GPU кадр упирается в JS главного потока. Зеркала — полный второй проход сцены каждый кадр: в городе
  30–45 % рендера. Уровень 30 при ×6: 61 fps; зеркало раз в 3 кадра — 79; без зеркал — 97.
  Симуляция ≈10 % (1–1,5 мс при ×6), текст 0,5–0,9 мс, DOM/HUD 0,1–0,2 мс.
- Без GPU композитор Chrome ≈13 мс/кадр на M4 при любом q (≈35–40 мс на ноутбуке), `backdrop-filter` —
  26 % его времени; отрисовка канвы на главном потоке 57 мс на q0 → 16 мс на q8 (лестница помогает
  только здесь). `alpha:false` на канве хуже (13,4 → 16,7 мс) — не делать.
- Куб салона без GPU: чтение WebGL в 2D 28 мс/кадр; салон 10 fps на q0, 28 на q8.
- `frameCost` не включает `simTick`; ступени q5–q8 меняют только DPR; в салоне буферы зеркал рисуются
  и при выключенных виджетах (стекло корпусов — картинка с 08.10, буфер не читает никто).
- В проходе зеркала дома идут до `BLD_MAXD` 250 м с картинками фасадов (`facRange` не знает о зеркале).

  — та же сцена из коммита в том же сеансе. В игре: `simCost` (EMA вокруг `simTick` в `frame`), строка
  `?perf=1` показывает `sim`. Логов нет. Файлы: `tools/laptop-bench.mjs`, `index.html` (`frame`, `perfTick`).

### Фаза 2 — зеркала (главный выигрыш с GPU)
- [x] Task 2: частота обновления зеркал по времени, не по кадру: `QUALITY[q].mirHz` (на зеркало,
  q0 20 Гц → q3 10 → q5 6), очередь по давности обновления; перетаскиваемое — каждый кадр. Буфер не
  рисуется, когда виджет скрыт (`!opt.mirrors`), в том числе в салоне. Сцена стоит — буфер не
  обновляется: сигнатура (поза машины, `mirAdj`, стоп/поворотник/аварийка, фаза светофора уровня,
  размер), если на уровне нет актёров. Убрать устаревший комментарий про стекло корпусов.
  Файлы: `index.html` (`render`, `renderMirror`, `QUALITY`, `Q_SLOW_MIRRORS`). Гейты: mirror-check,
  look-check (`@render-mirror-handle`), cabin-check (`@render-mirror-cube`).
- [x] Task 3: проход зеркала легче — замер снял задачу. Картинки фасадов в проход зеркала уже не
  попадают (заглушка `facRange` в зеркале не меняет числа заливок). Уровень 30: три прохода зеркал —
  1577 заливок против 917 у основного вида; без декалей −14 %, без домов −13 %, без препятствий −24 %,
  остальное — своя машина, земля, небо. Отдельной крупной статьи нет, выигрыш — частота (Task 2).

### Фаза 3 — композитор и куб салона (выигрыш без GPU)
- [x] Task 4: убрать `backdrop-filter` со всего, что лежит над живой канвой: `.panel` (`#topleft`,
  `#topright`), `#overlay`, тач-кнопки, `#pauseBtn`; фон сделать плотнее, чтобы читаемость не упала.
  Файлы: `index.html` (CSS). Гейты: menu-check, touch-check; снимки до/после.
- [x] Task 5: кэш куба салона: GL-проход и копия в свой 2D-холст куба — только при смене входа
  (поворот камеры относительно кузова `CUBE_ROT`, масштаб, размер, набор граней, наклон эстакады);
  иначе в кадре одна `drawImage` из кэша. Отдельный кэш на основной вид и салонное зеркало.
  Файлы: `index.html` (`drawCabinCube`). Гейты: cabin-check, cockpit-shots, look-check.
- [x] Task 6: программный рендер: определить по строке рендерера WebGL (SwiftShader, llvmpipe,
  Basic Render, Software) или по отказу WebGL. Тогда — старт с q4 (без промежуточных ступеней),
  одна подсказка на устройство «включи аппаратное ускорение в настройках браузера» (`pz_gpu_note`,
  не `trainer_*` — их зеркалит облако ЯИ) и строка в описании «Графика» в настройках; текст — по
  голосу продукта и `deslop-scan`. Лог: `console.info('[perf] программный рендер: <renderer>')` один раз.
  Файлы: `index.html` (запуск, `SETTINGS`, `toast`).

### Фаза 4 — лестница качества и телеметрия
- [x] Task 7: лестница — геометрия раньше разрешения: по профилю q4+ в городе добавить шаги
  (частота зеркал, тени и мелочь обустройства, дальность моделей машин, подписи) до ступеней DPR < 1;
  решение «вверх» — по `frameCost + simCost`. Замер (GPU, ×6, уровень 30): q0 — 45 fps, JS 18 мс, 1961 заливка;
  q5 — 118 fps, JS 6,6 мс, 754 заливки. Лестница с видеокартой уже снимает JS до q5, ступени q6–q8 нужны
  программному рендеру (отрисовка канвы на главном потоке 57 → 16 мс). Сделано: `mirDiv` (Task 2) и
  решение «вверх» по `frameCost + simCost`; ступени не переставлялись. Файлы: `index.html` (`QUALITY`, `qTick`). Гейты:
  touch-check («Графика: максимум»), orbit-check, city-check, facade-check `-range`.
- [x] Task 8: событие `perf_sample` — одно за сессию после 20 с езды: рендерер (обрезан), флаг
  программного, fps p50/p95, q и qBest, DPR, размер окна, `frameCost`, `simCost`, камера, уровень.
  Те же поля — в контекст отчёта «написать» (`fbCtx`). Файлы: `index.html` (`track`, `frame`, `fbCtx`),
  `docs/ANALYTICS.md`. Гейт: account-check (`@an-*`).
