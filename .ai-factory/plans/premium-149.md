# План: Премиум за 149 ₽ — уровни после 10-го, покупка с аккаунтом, промокоды

Владелец 11.10.2026: «разблокировка после 10 уровня только с покупкой премиума за 149 рублей… привязать к аккаунту,
чтобы без авторизации не мог купить… в настройках ввод промокода, который активирует премиум бесплатно — для
рекламы в соцсетях». Совет ECC 11.10.2026 (архитектор, скептик, прагматик, критик).

## Решения
- Закрыты уровни 11–32 (индексы 10–31), свои площадки открыты; граница — одна константа. Скептик и критик
  советовали закрывать с 20-го — владелец сказал «после 10-го».
- Только сайт (web/pwa, не во фрейме): в Яндекс Играх, VK, Telegram и во фрейме нет ни замка, ни промокода —
  своя оплата там запрещена, а входа в ЯИ нет.
- Покупка и промокод — только с аккаунтом (VK ID / Яндекс ID); премиум — энтитлмент `premium` на сервере.
- Промокод проверяет сервер: код ↔ кампания (метка соцсети), лимит активаций, срок, один код на аккаунт,
  попытки ввода ограничены; регистр не важен; `?promo=КОД` в адресе подставляет код в поле.
- Оплата — Robokassa по контракту spark (подпись SHA256 c Receipt и SuccessUrl2/FailUrl2, чек «none»/«service»,
  уведомление сверяется паролем №2, сумма «149.000000»), выдача доступа только по ResultURL.
- Замок за флагом `PAY_ON`: включается после активации магазина и пробной покупки владельцем с возвратом.
- Кто уже прошёл уровень после 10-го — доступ навсегда на этом устройстве (`pz_grand`).
- Путь новичка — только бесплатные уровни: 7 → 10 → 2 → 9 → 1.
- Готовность к экзамену у бесплатного игрока: экран называет потолок и что его снимает.

## За владельцем
Телефон для контактов → заявка магазина в Robokassa на модерацию → после активации `ROBOKASSA_IS_TEST=false`,
своя покупка и возврат → включаем `PAY_ON`. Промокоды для кампаний: `pz-account promo add КОД --max N --until ДАТА --tag vk`.
