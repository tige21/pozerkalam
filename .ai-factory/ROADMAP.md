# Роадмап «По зеркалам»

Стратегия из рыночной разведки (авг 2026): позиционирование «подготовка к практическому
экзамену», каналы — свой домен как ядро бренда + агрегаторы как трафик + B2B как чек.

## Майлстоуны

- [ ] **M1 · Перенос на РФ-сервер + pozerkalam.space + HTTPS** — новый VPS (Timeweb/Beget,
  200–400 ₽/мес), nginx (gzip, http2), certbot, перенос игры, обновлённый deploy-скрипт.
  Требование: доступность и из РФ без VPN, и через VPN — никаких гео-фильтров и
  DDoS-капч для зарубежных IP. Старый VPS (194.5.65.182) не трогать до подтверждения.
- [ ] **M2 · Аналитика** — два слоя:
  1. Серверная база: nginx access.log + GoAccess (гео/устройства/объёмы без JS,
     приватно, ноль внешних зависимостей).
  2. Поведенческая: Яндекс.Метрика (async-тег, не блокирует игру) + цели reachGoal:
     старт уровня, победа, провал экзамена, сдача экзамена, включение МКПП, повтор
     уровня — воронка «зашёл → доиграл → вернулся».
  Ограничение: счётчик ставится ТОЛЬКО в билд для своего домена — в билде для
  Яндекс Игр сторонняя аналитика запрещена правилами площадки (там своя статистика
  платформы). Деплой-скрипт вставляет тег подстановкой, репозиторий остаётся
  zero-dependency.
- [ ] **M3 · CDN** (условный — включать при росте трафика или деградации отклика).
  Файл 400 КБ статики — VPS с nginx держит тысячи посетителей/день без CDN.
  Варианты: Cloudflare free (плюс своя аналитика трафика; риск — периодические
  деградации из РФ, тогда держать DNS-only) или Yandex Cloud CDN (надёжнее для РФ,
  платный). Решение принимать по факту метрик из M2.
- [ ] **M4 · Яндекс Игры** — интеграция Games SDK (interstitial на рестарт/смену уровня,
  rewarded «показать идеальную траекторию», сейвы в SDK-хранилище), отдельный билд
  без Метрики, ZIP, модерация. Цель — трафик и соцдоказательство, не доход.
- [ ] **M5 · VK Play + Telegram Mini App** — тот же билд через тонкую абстракцию
  рекламного слоя; TG — вирусный канал «инструктор скинул ссылку в чат группы».
- [ ] **M6 · Лендинг и SEO** — pozerkalam.space как хаб: методика, разборы манёвров,
  страница для автошкол. Ниша органики «тренажёр по методике автошколы» пуста.
  Платную рекламу на игроков не покупать (CPL ученика 500–3000 ₽).
- [ ] **M7 · B2C-freemium** — база бесплатно, экзаменационный курс ~199–349 ₽/мес или
  ~990 ₽ разово; продавать за 2–4 недели до экзамена. Требует приёма платежей (ИП).
- [ ] **M8 · B2B-пилоты** — встройка в онлайн-школы ПДД (Рули Онлайн, Дром ПДД,
  SmartPDD — ни у кого нет тренажёра вождения) + white-label автошколам
  3–10 тыс. ₽/мес. Козырь питча — экзамен-режим с баллами регламента и «домашка»
  ученику между занятиями.
