# Логотип «По зеркалам»

Салонное зеркало заднего вида: рамка-капсула, сходящаяся дорога и жёлтая
стрелка машины внутри. Зеркало + дорога сзади = название проекта.

## Файлы

| Файл | Где применять |
|---|---|
| `mark.svg` | основной знак, тёмный фон |
| `mark-blue.svg` | вариант с голубой дорогой `#9fd0ff` |
| `mark-dark.svg` | знак для светлого фона (рамка `#08111b`) |
| `lockup.svg` / `lockup-dark.svg` | знак + надпись, шапка сайта, OG-картинка |
| `mark-small.svg` / `mark-small-dark.svg` | упрощённый знак без дороги для шапки сайта, 24–64 px |
| `icon.svg` | иконка приложения, **от 48 px** |
| `favicon.svg` | упрощённая версия без дороги, **до 32 px** |
| `png/` | растр: 512, 192, 180 (apple-touch), 32 |

## Палитра

- фон `#08111b`
- рамка и дорога `#ffffff` (на светлом — `#08111b`)
- стрелка `#ffd63c`
- альтернативная дорога `#9fd0ff`

## Минимальные размеры

Знак `mark.svg` держится до 64 px по ширине; ниже дорожные полосы сливаются
с рамкой — там ставится `mark-small.svg` (24–64 px, шапка сайта),
`icon.svg` (48–512 px, плитка приложения) или `favicon.svg` (16–32 px).
Это не запас прочности, а проверенная граница: см. контрольный лист
`build/shots/brand-sheet.png`, ряды «знак мелко» и «иконка».

## Надпись

Onest SemiBold (600), трекинг −1. Шрифт лежит в
`landing/public/font/onest-cyrillic.woff2` и грузится страницей, поэтому в
инлайн-SVG на сайте `<text>` рендерится верно. Для внешних площадок
(Яндекс.Игры, пресса) надпись надо перевести в кривые.

## Перерисовка растра

```
mkdir -p /tmp/pw && (cd /tmp/pw && npm i playwright-core@1.55)
PW_DIR=/tmp/pw node tools/brand-render.mjs
```

Скрипт кладёт PNG в `brand/png/` и собирает контрольный лист
`build/shots/brand-sheet.png` — на нём знак проверяется на тёмном, светлом
и на всех мелких размерах сразу.

## Нельзя

Растягивать, менять цвета вне палитры, вешать тени и градиенты, класть на
пёстрый фон без отступа (отступ = высота рамки зеркала), поворачивать.

## Где стоит сейчас

- лендинг: шапка `mark-small.svg`, вкладка `favicon.svg`, PWA `icon-192/512.png`,
  iOS `apple-touch-icon.png` (`landing/src/layouts/Base.astro`, `landing/public/`);
- игра: стартовый экран — инлайн-знак в `startHTML()`, вкладка — инлайн
  data-URI фавикон в `<head>`, PWA — `icon-192.png` / `icon-512.png` в корне.

Файлов в игру не добавлялось: `deploy-pozerkalam.sh` возит фиксированный
список (`index.html`, `sw.js`, `manifest.webmanifest`, два PNG), поэтому
фавикон живёт data-URI внутри `index.html`.
