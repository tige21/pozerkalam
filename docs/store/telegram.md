# Telegram Mini App — сценарий регистрации и тексты

Технически готово: `https://pozerkalam.space/play/` отдаёт CSP `frame-ancestors … https://web.telegram.org`, без `X-Frame-Options` — Telegram Web открывает игру в iframe, мобильные клиенты — в системном webview. Скрипт `telegram-web-app.js` не нужен: приложение запускается по ссылке как обычная страница (подключить позже только ради `WebApp.expand()`/темы — потребует правки CSP `script-src`).

## Диалог с @BotFather (по шагам)

1. `/newbot` → имя **По зеркалам** → юзернейм `pozerkalam_bot` (если занят: `pozerkalam_play_bot`). Сохранить токен — для Mini App он не нужен, но пригодится для рассылок.
2. `/setuserpic` → выбрать бота → загрузить `icon-512.png`.
3. `/setdescription` → текст «Описание бота» (ниже).
4. `/setabouttext` → текст «О боте» (ниже).
5. `/newapp` → выбрать бота →
   - **Title:** По зеркалам
   - **Short description:** текст «Описание приложения» (ниже)
   - **Photo 640×360:** `docs/store/telegram/app-640x360.jpg`
   - **Demo GIF:** пропустить (`/empty`)
   - **Web App URL:** `https://pozerkalam.space/play/`
   - **Short name:** `play`
6. `/setmenubutton` → выбрать бота → URL `https://pozerkalam.space/play/` → подпись кнопки **Играть**. Кнопка меню в чате с ботом открывает тренажёр без ссылок.
7. Проверка: открыть `https://t.me/pozerkalam_bot/play` с телефона и в Telegram Web — игра на весь экран, сенсорные кнопки видны, прогресс сохраняется между открытиями (localStorage webview).

Итоговая ссылка канала: **`https://t.me/pozerkalam_bot/play`** (параметр `?startapp=school` можно добавлять для пометки источника — игра его игнорирует, но он виден в статистике переходов Telegram).

## Тексты

**Описание бота (`/setdescription`, до 512 знаков):**
Тренажёр манёвров «По зеркалам» — параллельная парковка, гараж, эстакада, разворот в три приёма и экзаменационный маршрут с инспектором. Подсказки как у инструктора, честная физика, работает на телефоне. Нажми «Играть».

**О боте (`/setabouttext`, до 120 знаков):**
Тренажёр парковки и экзамена по методике автошколы. Открой Mini App «Играть».

**Описание приложения (`/newapp`, короткое):**
Отработай парковку, эстакаду и экзаменационный маршрут в браузере: подсказки по шагам, ориентиры в зеркалах, баллы по регламенту.
