# VK Mini Apps — регистрация и материалы

Технически готово: прод отдаёт CSP `frame-ancestors … https://vk.com https://*.vk.com` (десктоп vk.com и мобильный сайт m.vk.com), в игре есть шим `VKWebAppInit` — обязательное событие инициализации VK Bridge уходит площадке без подключения библиотеки, только при запуске с параметрами `vk_app_id`/`vk_platform` (мобильные клиенты и iframe vk.com передают их сами).

## Шаги в кабинете (владелец)

1. https://dev.vk.com → «Создать приложение» → тип **Mini App** («Встраиваемое приложение»), название **По зеркалам**, категория **Игры**.
2. Настройки → Размещение: **URL** `https://pozerkalam.space/play/` (один и тот же для iframe на vk.com, мобильной версии сайта и WebView в приложениях Android/iOS). Мобильное приложение и мобильная версия сайта — включить.
3. Иконка приложения — `icon-512.png` (кабинет сам просит нужные размеры; при необходимости уменьшить `sips -z N N icon-512.png --out icon-N.png`). Обложка/скриншоты — `docs/store/yandex/L01.jpg`, `L20.jpg`, `L27.jpg` (1920×1080).
4. Описание — «Полное описание» и короткая строка из `docs/store/yandex.md`.
5. Состояние → **Включено**. Проверить: открыть приложение из своего профиля на десктопе (iframe) и в мобильном приложении ВКонтакте (WebView, экран загрузки должен пропасть — это и есть `VKWebAppInit`), сыграть уровень, закрыть и открыть — прогресс на месте.
6. Каталог: подать заявку на модерацию (dev.vk.com/ru/mini-apps/catalog/moderation; минимум 3 дня). До модерации приложение доступно только по прямой ссылке `https://vk.com/app<ID>` — её можно отдавать в сообщества автошкол сразу.

## Ссылка канала

`https://vk.com/app<ID>` (ID появится после создания). Параметр `?ref=school` игра игнорирует, статистика переходов — в кабинете приложения.

## Что не покрыто (по решению владельца)

- **Одноклассники** (ok.ru, m.ok.ru) — площадка доступна из того же кабинета, но CSP прода их не пускает: добавить `https://ok.ru https://*.ok.ru` в `frame-ancestors` (`deploy-pozerkalam.sh`, строка с `add_header Content-Security-Policy`) и задеплоить.
- **VK Play** (vkplay.ru) — отдельный каталог игр с другой формой подачи; в CSP нужен `https://*.vkplay.ru`. Не входит в M5, делать только если появится смысл после VK Mini Apps.
