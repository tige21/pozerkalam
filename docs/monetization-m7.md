# M7 · B2C-freemium — памятка для решения (сентябрь 2026)

Статус: **решение за владельцем**. Код не писался. Ниже — что известно, какие варианты есть и пять вопросов, после ответов на которые M7 превращается в обычный план.

## Исходные якоря (ROADMAP + разведка авг 2026)

- База бесплатно, «экзаменационный курс» ~199–349 ₽/мес или ~990 ₽ разово; продавать за 2–4 недели до экзамена. Якоря рынка: ПДД-подписки 129–449 ₽/мес, City Car Driving ~990 ₽.
- Позиционирование «подготовка к практическому экзамену», не «симулятор». Платящая привычка — вокруг экзамена.
- Ограничение из ROADMAP «требует ИП» — **устарело**: для сайта и Яндекс Игр достаточно самозанятости (НПД), см. ниже.

## Что бесплатно, что платно — три варианта (нужен выбор)

| | A · «Экзаменационный курс» | B · «Экзамен + аналитика» | C · «Попытки» |
|---|---|---|---|
| Бесплатно | уровни 1–19 (двор, дриллы габаритов), демо, МКПП выкл | всё, кроме уровня 27 | всё; экзамен — 1 попытка в день |
| Платно | 20–27 (эстакада, задний ход, остановка, город, экзамен-маршрут) + МКПП | экзамен-маршрут, протокол с картой ошибок, «готовность %», кнопки «отработать» | безлимит экзамена + протокол; в ЯИ — попытка за rewarded-рекламу |
| Плюс | ясно, за что платят; совпадает с моментом «экзамен через 2 недели» | максимум охвата и соцдоказательства в ЯИ/TG/VK | не режет контент, мягко ведёт к оплате |
| Минус | бесплатная часть не показывает главную ценность (экзамен) | «за деньги — один уровень» звучит слабо | сложнее объяснить, нужна серверная или честная локальная блокировка |

Рекомендация агента: **A для сайта и Telegram** (там продаётся «курс»), **C для Яндекс Игр** (там уже есть rewarded-реклама и покупки в Ян, а бесплатный охват важнее). Но это ваш выбор.

## Технически: что понадобится в игре, когда решение принято

Энтитлмент-слой по образцу рекламного (`window.ADS`): `window.PAY = { has(id), buy(id, onOk), restore() }`.
- **Игра** (`index.html`): единая точка `entitled('course')`; замки на карточках уровней и в `loadLevel` (без оплаты — экран «Курс» с ценой и кнопкой), меню «Восстановить покупку», хранение `trainer_ent` в localStorage (+ облако ЯИ уже зеркалит `trainer_*`). ~1 день.
- **Билд ЯИ** (`build-yandex.sh`): адаптер на `ysdk.getPayments({signed:false})` → `purchase`/`getPurchases`; товар «course» в консоли. ~0,5 дня. Серверной части не нужно.
- **Сайт**: без бэкенда честной проверки нет. Минимум — платёжная ссылка ЮKassa/Prodamus + выдача кода доступа (вручную на старте или webhook → страница с кодом); код проверяется в игре по HMAC с секретом, зашитым в билд (защита «от честных»). С бэкендом (webhook + выдача подписанного токена) — ещё ~1–2 дня. Для варианта C с суточным лимитом на сайте — только локальный счётчик (обходится очисткой localStorage; для B2C приемлемо).
- **Метрика**: цели `paywall-view`, `purchase-ok` в `track()` — уже есть механизм reachGoal.

## Пять вопросов владельцу

1. Юрформа на старт: **самозанятость сейчас** (хватает для сайта и ЯИ, лимит 2,4 млн ₽/год) или сразу ИП (нужен для VK Pay и удобнее для B2B по M8)?
2. Состав платного: **A / B / C** из таблицы (можно разный для сайта и ЯИ)?
3. Цена и модель: разово ~990 ₽ («курс навсегда»), дешевле ~499 ₽, или подписка 199–349 ₽/мес (в ЯИ подписок нет — там только разово)?
4. Первый канал денег: **ЯИ** (без бэкенда, но до 30 % удержания и модерация покупок) или **сайт** (комиссия ~3 %, но нужна выдача доступа после оплаты)?
5. Telegram Stars — пробовать параллельно (крипто-выплата) или не трогать?
