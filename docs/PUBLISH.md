# Публикация «По зеркалам» на площадках

Артефакты собраны, аккаунты и кнопки «отправить» — за владельцем.

## Яндекс Игры (M4)

Материалы формы (тексты, категория, скриншоты, чек-лист песочницы) — `docs/store/yandex.md`,
скриншоты 1920×1080 — `docs/store/yandex/`.

1. Собери свежий пакет: `./build-yandex.sh` → `build/yandex.zip` (index.html в корне,
   без Метрики/PWA, с адаптером Games SDK: реклама + облачные сейвы). Перед загрузкой
   прогони гейт: `PW_DIR=/tmp/pw node tools/yandex-check.mjs` — он открывает собранный
   билд под мок-SDK и падает, если регистрация SW осталась, адаптер не встал или
   реклама не ставит игру на паузу.
2. Кабинет разработчика: https://games.yandex.ru/console/ — «Создать игру».
3. Черновик: название «По зеркалам», категория «Гонки»/«Обучающие», описание из
   лендинга, скриншоты (сними в игре: уровень 1, эстакада 20, экзамен 27,
   иконка 512 из репо), ориентация — альбомная.
4. Загрузи `yandex.zip`, в песочнице проверь: загрузка, реклама по кнопке
   «Повторить» (после 3 мин сессии), rewarded из меню «Подсказка: траектория»,
   сохранение прогресса между заходами.
5. Отправь на модерацию. Требования: https://yandex.ru/dev/games/doc/ru/concepts/requirements

## Telegram Mini App (M5)

Пошаговый диалог с BotFather, тексты и фото 640×360 — `docs/store/telegram.md`, `docs/store/telegram/`.

1. @BotFather → `/newbot` → имя `ПоЗеркалам`, юзернейм вида `pozerkalam_bot`.
2. `/newapp` → выбрать бота → Web App URL: `https://pozerkalam.space/play/`,
   короткое имя `play`. Иконка — icon-512.png из репо.
3. Готово: игра открывается по t.me/<бот>/play. Кидай ссылку в чаты групп
   автошкол — это и есть канал.

## VK Mini Apps / VK Play (M5)

Шаги кабинета, материалы и примечание про Одноклассники/VK Play (CSP) — `docs/store/vk.md`. В игре есть шим `VKWebAppInit`.

1. https://dev.vk.com → «Создать приложение» → тип «Встраиваемое приложение».
2. URL приложения: `https://pozerkalam.space/play/` (iframe-доступ уже разрешён
   CSP: vk.com и *.vk.com).
3. Название «По зеркалам», иконки из репо, категория «Игры».
4. После проверки — включить видимость в каталоге.

## Что уже готово технически

- CSP `frame-ancestors` пускает yandex/playhop/vk/telegram.
- В веб-версии (/play/) реклама выключена (no-op), в ЯИ-билде — через SDK
  с кулдауном 180 с и щадящим первым минутам.
- Облачные сейвы ЯИ зеркалируют trainer_* поверх localStorage (merge, не затирая
  локальный прогресс).
