# Цена глазами персон: выводы

Задача доски #280, фаза 3 из 4. Фокус-группа 04.10.2026: 10 персон-покупателей оценили 4 варианта
из `docs/monetization-m7.md` (вопросы 2 и 3), каждая в своём порядке и под нейтральными номерами.
Полные ответы — `reports/demand/price-panel.md` (генерат). Повторить:

```bash
node tools/demand/price-setup.mjs                         # файлы персон с вариантами, order.json
# каждой персоне — tools/demand/panel-price.md, ответ в build/demand/price/answers/pNN.json
SSR_DIR=/tmp/ssr node tools/demand/ssr.mjs --calibrate    # проверить шкалу до сводки
SSR_DIR=/tmp/ssr node tools/demand/price-report.mjs       # сводка
```

Варианты (`tools/demand/offers.json`): **A990** и **A499** — «Экзаменационный курс» (уровни
20–32: площадка, город, экзамен-маршрут) навсегда за 990 и 499 ₽; **A249m** — то же за 249 ₽ в
месяц с автопродлением; **C499** — всё бесплатно, экзамен-маршрут раз в день, безлимит — 499 ₽
навсегда.

## Что показала группа

| вариант | прямая оценка 1–5 | «никогда» | выбрали бы | SSR |
|---|---|---|---|---|
| A499 | 3,26 | 0 % | 100 % | 2,91 |
| A990 | 1,98 | 38 % | 0 % | 2,81 |
| A249m | 1,95 | 64 % | 0 % | 2,67 |
| C499 | 1,65 | 50 % | 0 % | 2,91 |

1. **Разово, без подписки — 10 из 10.** Причины одни и те же: «забуду отменить», «ещё одна
   дыра», «муж увидит списание», «родители спросят, куда уходят деньги». Это повторяет живые
   отзывы фазы 1 об автопродлении (C017, C018, C032). Подписка отпадает.
2. **499 ₽, а не 990.** У 990 «никогда» говорят 38 % против 0 % у 499. Персоны сравнивают цену
   с часом инструктора: 499 ₽ для них «в три-четыре раза дешевле доп. часа», а 990 ₽ — «уже
   почти час, а польза не доказана». Взвешенные медианы цены курса одним платежом:
   подозрительно дёшево — 99 ₽, выгодно — 300 ₽, дорого — 700 ₽, не куплю — 1 500 ₽. 499 ₽
   попадает между «выгодно» и «дорого», 990 ₽ — выше «дорого».
3. **Лимит попыток экзамена (C) не продаёт.** «Одной бесплатной попытки в день хватит, платить
   незачем» — у всех, кто сдаёт; водителям с правами экзамен не нужен вовсе. Для Яндекс Игр, где
   M7 советовал вариант C, это довод сравнить его с rewarded-рекламой, а не с покупкой.
4. **Водителям с правами нужен город, а не экзамен.** p06 и p09 взяли бы курс ради города
   («ездить без мужа рядом», «кольцо и трафик — то, чего я боюсь»), p08 и p10 не взяли бы ничего:
   их беда (двор, габариты) в бесплатной части. Название «Экзаменационный курс» говорит только с
   учениками; для сегмента B ценность платной части — город.
5. **Момент — когда упрёшься.** Для A499: «когда упрусь в бесплатное» — 64 %, «перед экзаменом» —
   28 %, «сразу» — 8 %. Карточка при входе в уровень 20 стоит там, где надо; на старте её не
   показывать.

Что останавливает при 499 ₽: механика (p02, p03 — «сцепление не отработаешь»), сомнение, что
телефон даст чувство габаритов (p01, p06, p09), «вымышленный город не мой район» (p05),
подросток меряет ценой Steam: 100–150 ₽ (p04).

**SSR здесь не судья.** Разброс SSR между вариантами 2,67–2,91, а C499 он поставил наравне с
A499, хотя прямая оценка, выбор и тексты против. Ответ «бесплатной попытки хватит, платить
незачем» не содержит слов отказа, и эмбеддинг кладёт его в середину шкалы. Калибровка
(`ssr.mjs --calibrate`) проверяет явные фразы, а не такие. Порядок показа на ответы не влиял:
SSR по местам 1–4 — 2,84 / 2,93 / 2,75 / 2,78, без наклона.

## Что взять в фазу 4

- Карточка при входе в уровень 20: **один платёж, без подписки, «дешевле часа с инструктором»**,
  СБП рядом с картой.
- Цена — **499 ₽**. Если трафика хватит на два плеча, второе — 790 ₽: это за медианой «дорого» и
  покажет, круто ли падает интерес выше неё. 990 ₽ не ставить.
- Не прятать «на автомате»: это главный стоп у учеников на механике, и честнее, чтобы они узнали
  это до клика, а не после оплаты.
- Решение о цене — по кликам фазы 4, не по этой таблице.

Фаза 4 запущена с ценой **249 ₽** (решение владельца) — `fake-door.md`.
