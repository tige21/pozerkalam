# По зеркалам

Тренажёр манёвров для тех, кто получил права и боится выезжать: двор, габариты,
экзаменационные упражнения, город и экзаменационный маршрут. Работает в браузере,
без установки — <https://pozerkalam.space/play/>.

Лендинг проекта: <https://pozerkalam.space/>.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | вся игра одним файлом: CSS, разметка, физика, софтверный 3D-рендер на Canvas 2D, 32 уровня и экзамен. Зависимостей и сборки нет — файл открывается с `file://` |
| `landing/` | лендинг на Astro (`npm run build` → `dist/`) |
| `tools/` | проверки в headless-браузере: регрессия показов, аудит уровней, кабина, зеркала, МКПП, производительность |
| `learner.js` | скриптовый «ученик»: читает карточку инструктора и делает только то, что в ней написано — тест учебных текстов, а не физики |
| `server/` | приёмник отзывов (Python + systemd + nginx) |
| `docs/` | публикация в сторы, схема обратной связи, монетизация |
| `brand/` | знак, логотип, иконки |
| `CLAUDE.md` | инженерный журнал: почему код устроен так, а не иначе |

## Запуск

```bash
open index.html          # игра
cd landing && npm ci && npm run dev   # лендинг
```

## Проверки

```bash
node tools/level-audit.mjs      # уровни: показы, карточки, чипы, касания
node tools/cockpit-shots.mjs    # кабина, порядок граней, кадр
node tools/mt-check.mjs         # механическая коробка, 38 правил
node tools/demo-vio.mjs 27 31   # показы города под детекторами нарушений
```

Учебные тексты проверяются прогоном `learner.js` в консоли страницы:
`const stop = learnerStart()`.

## Деплой

```bash
./deploy-pozerkalam.sh   # прод: лендинг в корень, игра в /play/, следом зеркало
./build-yandex.sh        # сборка для Яндекс Игр → build/yandex.zip
```

Деплой идёт только из чистого дерева, отправленного в origin: на сервер уезжает
ровно тот код, что лежит в репозитории. Ключи и ID счётчика — в `.deploy.env`,
его в git нет.
